# fastauc

This is an alias. `pip install fastauc` installs
[`pyfastauc`](https://pypi.org/project/pyfastauc/), the actual package, at
the same version. Either way you `import fastauc`.

Exact, fast classification, calibration and ranking metrics for Python,
written in Rust: ROC-AUC, average precision, GAUC, NDCG, MRR, MAP, log loss,
ECE, bootstrap and DeLong intervals, paired tests, a scikit-learn drop-in,
and exact streaming. Tied scores never leak row order.

Source and documentation: https://github.com/hen-ml/fastauc
